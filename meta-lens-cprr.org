* Context

The primary experiment established:
- Verbosity peaks as angular distance at L18 (output_preparation)
- Style axis occupies ~15-20% of angular space in ℝ¹⁰²⁴
- Sweet spot for steering: L15-16 (stability > 0.95, SNR 3-4%)
- Terse direction is near a collapse boundary; verbose is not symmetric

This document runs a second-order experiment: instead of terse↔verbose
as the contrastive pair, we use *meta-framing* as the axis.

The hypothesis is that four philosophical lenses — Meadows, Wittgenstein,
Foucault, Freud — each install a different terministic screen, and each
screen diverges from a direct answer at a *different layer*.

Priority order reflects comprehension depth, not importance:
Meadows > Wittgenstein > Foucault > Freud.

Freud is last not because he is wrong but because the experiment
should produce results before we need him.

* Part I: Meadows — Systems Thinking Lens
:PROPERTIES:
:TAG: meadows
:PRIORITY: 1
:END:

** Background

Donella Meadows, /Thinking in Systems/ (2008).

The core operation: refuse to answer a question in isolation.
Every question is a node with upstream causes and downstream effects.
The systems thinker asks: what are the stocks, flows, feedback loops,
and delays that make this question possible? What changes if the system
is perturbed?

Applied to "why does bread rise":
- Direct answer: yeast consumes sugar, produces CO₂, bubbles expand dough
- Meadows answer: yeast is a stock; sugar is a flow; CO₂ production is a
  feedback-dependent rate; temperature is a delay parameter; gluten
  network is a constraint on the stock's behavior; the baker is an
  external agent with a goal variable

The Meadows answer is not *longer* — it is *differently shaped*.
It maps the causal neighborhood rather than traversing the causal chain.

** Conjecture Set

*** CPRR-M1: Systems framing diverges later than verbosity
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* The Meadows contrastive pair (causal_graph vs direct)
diverges at a later layer than the verbosity pair, with peak angular
distance at L20-22 (output_preparation) rather than L18.

*Rationale:* Verbosity modulates *how much* to say about the same
thing. Systems framing modulates *what the answer is about*. The latter
requires a higher-level decision — one that happens after the semantic
content is committed (L12-16) but before token generation begins (L23+).

*Test:*
#+begin_src python :tangle experiments/07-meadows-sweep/run.py :mkdirp t
"""
Meadows sweep — contrastive activation sweep: direct vs systems-framing.

Uses register_forward_hook (same approach as experiments 01-06), not
transformer_lens. Captures residual stream at all 28 layers via hooks.

Usage:
    python experiments/07-meadows-sweep/run.py
    python experiments/07-meadows-sweep/run.py --cprr
"""
import json
import os
import sys
import time
from pathlib import Path

import torch
import torch.nn.functional as F
from transformers import AutoModelForCausalLM, AutoTokenizer

sys.path.insert(0, str(Path(__file__).resolve().parent.parent.parent))
from actadd import MODEL_ID

NUM_LAYERS = 28

PROBES = [
    ("Why does ice float on water?",
     "Map the system that causes ice to float: the stocks, flows, and feedback loops involved, and what changes if any variable shifts."),
    ("How does a vaccine work?",
     "Map the system through which vaccination produces immunity: stocks, flows, feedback loops, delays, and failure modes."),
    ("Why do we dream?",
     "Map the system that produces dreaming: what are the inputs, what are the feedback mechanisms, what does the system regulate?"),
    ("What causes inflation?",
     "Map the causal system that produces inflation: stocks (money supply, goods), flows (spending, production), feedback loops (expectations, policy), delays."),
    ("How does bread rise?",
     "Map the system that causes bread to rise: yeast as a stock, sugar as a flow, CO2 as output, gluten network as constraint, temperature as delay parameter."),
]


def get_all_layer_activations(model, tokenizer, prompt):
    """Capture residual stream at all layers via hooks."""
    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
    layer_acts = {}
    handles = []
    for layer_idx in range(NUM_LAYERS):
        def make_hook(idx):
            def hook_fn(module, input, output):
                hidden = output[0] if isinstance(output, tuple) else output
                layer_acts[idx] = hidden[0, -1, :].detach().clone()
            return hook_fn
        handle = model.model.layers[layer_idx].register_forward_hook(make_hook(layer_idx))
        handles.append(handle)
    with torch.no_grad():
        model(**inputs)
    for h in handles:
        h.remove()
    return layer_acts


def angular_distance(a, b):
    cos = F.cosine_similarity(a.unsqueeze(0), b.unsqueeze(0))
    return (1 - cos).item()


def main():
    output_dir = str(Path(__file__).resolve().parent / "output")
    os.makedirs(output_dir, exist_ok=True)

    print(f"Loading {MODEL_ID}...")
    tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)
    model = AutoModelForCausalLM.from_pretrained(
        MODEL_ID, dtype=torch.float16, device_map="auto"
    )
    model.eval()

    results = []
    for direct, systems in PROBES:
        act_direct = get_all_layer_activations(model, tokenizer, direct)
        act_systems = get_all_layer_activations(model, tokenizer, systems)
        for layer in range(NUM_LAYERS):
            dist = angular_distance(act_direct[layer], act_systems[layer])
            results.append({"layer": layer, "probe": direct[:30], "angular_dist": round(dist, 6)})
        print(f"  {direct[:40]:40s} done")

    output_path = os.path.join(output_dir, "meadows_sweep.json")
    with open(output_path, "w") as f:
        json.dump(results, f, indent=2)
    print(f"Saved: {output_path}")


if __name__ == "__main__":
    main()
#+end_src

would mean systems framing is a style modulation, not a meta-reframing.

*Confirmed if:* Peak > L19 across at least 3 of 5 probe pairs.

* Part II: Wittgenstein — Language Game Lens
:PROPERTIES:
:TAG: wittgenstein
:PRIORITY: 2
:END:

** Background

/Philosophical Investigations/ (1953). The key move: meaning is use.
"Why is the sky blue?" is not one question — it is multiple questions
depending on which language game is being played.

- Physics classroom game: correct answer is Rayleigh scattering
- Child asking game: correct answer is "because sunlight bounces"
- Poet's game: correct answer might be silence or a line
- Courtroom game: correct answer depends on what is being proved

The Wittgenstein lens asks: *which game is this?* before answering.
Applied as a meta-frame, the model would identify the game being played
before producing an answer appropriate to that game — or would note
that the question assumes a game that may not be the right one.

** Conjecture Set

*** CPRR-W1: Language-game identification occurs at output_preparation
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* The Wittgenstein contrastive pair (which_game vs direct)
diverges at L18-20, same region as Meadows but with different direction
in activation space (low cosine similarity between Meadows vector and
Wittgenstein vector at same layer).

*Rationale:* Both Meadows and Wittgenstein are meta-frames that require
knowing the direct answer before refusing to give it. But they refuse
differently — Meadows maps causes, Wittgenstein maps contexts. If they
share a layer but not a direction, the layer is "meta-frame decision"
and the direction encodes which meta-frame.

:PROPERTIES:

* Part III: Foucault — Power/Knowledge Lens
:PROPERTIES:
:TAG: foucault
:PRIORITY: 3
:END:

** Background

/Discipline and Punish/ (1975), /The Archaeology of Knowledge/ (1969).

The Foucauldian lens asks: who is authorized to produce this knowledge,
through what institutional apparatus, and whose knowledge is excluded
by that authorization?

"Why is the sky blue" contains a hidden claim: that mechanistic
reductionist physics produces the valid answer. The shepherd who has
watched skies for forty years has a different answer that the discourse
excludes. The physicist's answer is not truer — it is *authorized*.

Applied as a meta-frame, the model would interrogate the authorization
structure rather than (or before) producing the authorized answer.

This is the most politically charged of the four lenses.
It is useful because it makes the selection/deflection structure
of any answer *visible*.

** Conjecture Set

*** CPRR-F1: Foucault vector is distinct from Meadows and Wittgenstein
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* At L20, the Foucault vector has cos_sim < 0.5 with
both Meadows and Wittgenstein vectors.

*Rationale:* Meadows asks about causal structure. Wittgenstein asks
about contextual fit. Foucault asks about power. These are three
different operations. If they are geometrically distinct, meta-framing
is a multi-dimensional space in activation space, not a single axis.

*** CPRR-F2: Foucault injection produces who/authorized vocabulary
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* Injecting Foucault vector at L20 causes the model to
produce responses mentioning authorization, expertise, exclusion, or
power without being prompted to.

* Part IV: Freud — Suppressed Premise Lens
:PROPERTIES:
:TAG: freud
:PRIORITY: 4
:END:

** Background

/Jokes and Their Relation to the Unconscious/ (1905).
/The Interpretation of Dreams/ (1900).

The Freudian lens is structurally different from the other three.
Meadows, Wittgenstein, and Foucault all ask *about* the question.
Freud asks what the question is *avoiding*.

Every question has a suppressed premise — something that would be
uncomfortable to state directly. The joke-work finds this and releases
it via lateral connection and a third party (the listener).

Applied as a meta-frame: what is the anxiety behind "why does bread
rise?" The domesticity of it. The dependence on an organism you cannot
control. The fact that it is controlled rot. The humor (if any) lives
in recognizing and releasing that.

Freud is last because:
1. The experiment should work before we need him
2. Humor as a meta-frame requires the semantic content (L12-16) plus
   the structural decision (L18-22) — it is the most complex injection
3. The suppressed premise varies more by cultural context than the
   other three, making the direction less stable across probe pairs

** Conjecture Set

*** CPRR-Fr1: Freud vector peaks earlier than Meadows (L15-16)
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* The Freud contrastive pair diverges at L15-16, earlier
than Meadows/Wittgenstein/Foucault (L18-22).

*Rationale:* Finding the suppressed premise requires knowing the
semantic content of the question (L12-16) — you cannot find what is
being avoided without first processing what is being said. The other
three meta-frames are decisions about *how to respond*; Freud is a
decision about *what the question really is*. That earlier decision
may show up earlier in the residual stream.

If confirmed, Freud-as-lens requires a different injection site than
the others — L15 not L20.

*** CPRR-Fr2: Humor injection is a two-site operation
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* Effective humor injection requires:
- L15: install "find suppressed premise" direction
- L20: install "release via lateral connection" direction

Single-site injection at either layer alone produces neither
the suppressed content nor the release structure.

*Rationale:* The joke requires two operations: finding the anxiety
(semantic, L15) and constructing the release (structural, L20).
This is the most complex multi-layer hypothesis in this document
and the least testable without a joke-quality metric.

*** CPRR-Fr3: Freud direction has lowest cross-pair stability
:PROPERTIES:
:STATUS: open
:CONFIDENCE: prior
:END:

*Conjecture:* The Freud vector has direction_stability < 0.80 across
probe pairs — lower than Meadows, Wittgenstein, and Foucault.

*Rationale:* The suppressed premise behind "why does bread rise" is
different from the suppressed premise behind "what causes inflation."
The anxiety is question-specific. Therefore the direction in activation
space is less generalizable. If this is confirmed, a Freud steering
vector would need to be computed per-question rather than as a
universal meta-frame vector.

* Key Open Question

If M1 and W1 are both confirmed (both peak at L20-22) but W2 is also
confirmed (vectors non-parallel), then the residual stream at L20-22
contains a *multi-dimensional meta-framing space* — not a single
"direct vs meta" axis but a space where different meta-operations
(causal mapping, context identification, power interrogation) are
geometrically distinct.

This would mean:
1. A single meta-lens injection vector is insufficient
2. Each lens requires its own direction at L20-22
3. The "meta-frame decision" layer is doing richer work than
   the verbosity layer — it is encoding *which kind of thinking*
   to apply, not just *how much* to say

That would update layer-roles.json significantly:

#+begin_example
output_preparation (18-22):
  current:  "formatting, response structure"
  revised:  "meta-frame selection, response type decision,
             causal/contextual/epistemic mode encoding"
#+end_example

This is the result worth getting to before running Freud.
