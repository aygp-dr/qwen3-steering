* Qwen3-0.6B Architecture Summary

| Parameter          | Value              |
|--------------------+--------------------|
| Transformer layers | 28                 |
| Hidden size        | 1024 (d_model)     |
| FFN width          | 4096 (SwiGLU)      |
| Attention heads    | 16 query, 8 KV     |
| Attention type     | Grouped Query (GQA)|
| Normalization      | RMSNorm            |
| Position encoding  | RoPE               |
| Vocab size         | 151,936            |
| Total params       | ~751M              |

The model has *28 transformer layers* (indexed 0-27). Each layer contains
self-attention + feed-forward, with residual connections. The residual stream
is a 1024-dimensional vector that flows through all 28 layers sequentially.

* How a Steering Vector Is Computed (Terse/Verbose Example)

The steering vector is the *difference in activation patterns* between two
contrastive prompts at a chosen layer.

The activations are captured at a single layer (typically layer 12-18 for
Qwen3-0.6B) and mean-pooled across token positions to produce one
1024-dimensional vector per prompt. The difference encodes the "terse
direction" in activation space.

* The Injection Mechanism

** Single-Layer Injection (ActAdd)

A PyTorch =register_forward_hook= is attached to one transformer layer.
During generation, *every forward pass through that layer* adds the steering
vector to the residual stream:

#+begin_example
h_L' = h_L + α · v
#+end_example

Where:
- =h_L= is the hidden state at layer L (shape: [batch, seq_len, 1024])
- =v= is the steering vector (shape: [1024]), broadcast across all positions
- =α= is the scaling factor (typically 2.0 for raw vectors)

* Is It Recursive? No — It Is Repeated per Token

The hook fires once per layer per forward pass. But autoregressive generation
calls the model *once per output token*. This is where the repetition comes
from: it is not recursion within a single pass, but iteration across tokens.

#+begin_src mermaid :file token-iteration.png :exports results
sequenceDiagram
    participant G as Generator
    participant M as Model (28 layers)
    participant H as Hook @ Layer 12

    Note over G: Prompt: "Explain gravity"
    G->>M: Forward pass (all prompt tokens)
    M->>H: Layer 12 fires
    H->>M: h₁₂' = h₁₂ + αv (all positions)
    M->>G: logits → token₁ = "Mass"

    G->>M: Forward pass (token₁)
    M->>H: Layer 12 fires
    H->>M: h₁₂' = h₁₂ + αv
    M->>G: logits → token₂ = "curves"

    G->>M: Forward pass (token₂)
    M->>H: Layer 12 fires
    H->>M: h₁₂' = h₁₂ + αv
    M->>G: logits → token₃ = "spacetime"

    Note over G: ... repeats for every generated token
#+end_src

** Key insight

The steering vector is added at the *same magnitude* every time. It does not
accumulate in the residual stream across tokens (each token's forward pass
starts fresh from the KV cache + new token embedding). The effect is
*constant pressure*, not compounding.

* What Happens at Scale: 128 vs 1024 Tokens

** Per-token cost

Each generated token requires one forward pass through all 28 layers. The
hook adds a single vector addition at the hooked layer(s). This is O(d_model)
= O(1024) — negligible compared to attention (O(seq_len × d_model)).

Each vector addition is a 1024-element add — trivial. The dominant cost
remains attention's O(n²) over the growing KV cache, not the steering.

* The Residual Stream View

The residual stream is the central "highway" through the transformer. Each
layer reads from it, computes, and writes back. The steering hook intercepts
this highway at one point.

The perturbation at layer 12 propagates through layers 13-27. Later layers
can amplify, dampen, or redirect the effect. This is why layer choice matters:
too early (layers 0-5) and attention overwrites it; too late (layers 24-27)
and there are not enough downstream layers to propagate the effect into
meaningful token predictions.

* Terminology Reference

| Term                 | Meaning                                                              |
|----------------------+----------------------------------------------------------------------|
| Layer                | One transformer block (attention + FFN + residual connections)       |
| Residual stream      | The d_model-dimensional vector flowing through all layers            |
| Forward pass         | One complete traversal of all 28 layers for one token                |
| Hook                 | A callback registered on a layer, fires every forward pass           |
| Steering vector      | The contrastive activation difference encoding a behavioral axis     |
| Alpha (α)            | Scaling factor controlling intervention strength                     |
| Autoregressive       | Generating one token at a time, each conditioned on all previous     |
| KV cache             | Stored key/value matrices from prior tokens (avoids recomputation)   |
| Superposition        | Multiple features compressed into fewer dimensions                   |
| GQA                  | Grouped Query Attention — queries share key/value heads              |
