Mermaid diagrams for exploring how activation steering works — architecture,
data flow, methodology, and decision trees. These render on GitHub natively
and can be exported via =mmdc= (mermaid CLI) or org-babel.

Theoretical grounding: Kenneth Burke's "terministic screens" (1966) — every
vocabulary is a selection of reality. The lens eval measures which terministic
screen the model applies to neutral prompts. Déformation professionnelle
made quantitative.

* 4. CPRR Methodology

Conjecture → Proof → Refutation → Refinement lifecycle.

** 4.1 CPRR Loop

#+begin_src mermaid :file diagrams/cprr-loop.svg
graph TD
    C[Conjecture<br/>Propose testable claim] --> E[Experiment<br/>Layer sweep, style metrics]
    E --> D{Evidence supports<br/>the claim?}

    D -->|Yes| P[Proof<br/>Record evidence, promote]
    D -->|No| R[Refutation<br/>Record counter-evidence]

    R --> RF[Refinement<br/>Update hypothesis,<br/>adjust parameters]
    RF --> C

    P --> N[Next hypothesis<br/>in dependency chain]
    N --> C

    subgraph "Example: C-26 → C-27"
        C26[C-26: Unit vec α=0.20<br/>optimal at layer 10] --> E26[Sweep layers 10-20]
        E26 --> R26[Refutation: all layers<br/>identical output]
        R26 --> RF26[Refinement: remove<br/>normalization, raise α]
        RF26 --> C27[C-27: Raw vec α=2.0<br/>optimal at layer 12]
        C27 --> E27[Sweep + baseline compare]
        E27 --> P27[Proof: 149 → 16 words]
    end

    style P fill:#2d6a4f,stroke:#fff,color:#fff
    style R fill:#d00000,stroke:#fff,color:#fff
    style RF fill:#e9a545,stroke:#000,color:#000
