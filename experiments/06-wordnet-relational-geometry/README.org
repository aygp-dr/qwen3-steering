#+TITLE: Experiment 06: WordNet Relational Geometry
#+DATE: 2026-03-06
#+STATUS: pending

* Goal

Test whether the residual stream encodes WordNet relationships as stable,
distinct directions. Ground truth from an external graph — no prompt
engineering, no topic drift, verifiable precision/recall.

* Why This Is Better Than Verbosity

| Property               | Verbosity experiment   | WordNet experiment        |
|------------------------+------------------------+---------------------------|
| Ground truth           | None (subjective)      | WordNet graph (117K syns) |
| Relationship clarity   | Continuous spectrum     | Discrete, categorical     |
| Drift detection        | Hard to measure        | If "dog->animal" also     |
|                        |                        | activates "dog->pet food" |
|                        |                        | you know the direction    |
|                        |                        | is noisy                  |
| Linguistic necessity   | Style is optional      | Hypernyms are required    |
|                        |                        | for generalization        |

* Three Relationships Tested

| Relation | Example       | Direction meaning      | WordNet edge |
|----------+---------------+------------------------+--------------|
| hypernym | dog -> animal | generalization         | is-a         |
| antonym  | hot -> cold   | negation/opposition    | antonym      |
| meronym  | wheel -> car  | part-to-whole          | part-of      |

15 curated pairs per relation (45 total). Words chosen to be likely
single-token in Qwen3's 151K vocabulary.

* Layer Predictions

#+begin_example
L0-7:   token identity, no relational structure
L8-11:  word sense disambiguation — hypernyms start here
L12-16: relational encoding — hypernym/hyponym direction stable
L18+:   output preparation, relations used but not encoded cleanly
#+end_example

* Key Question

Are hypernym and antonym *orthogonal* directions at L14?

- If orthogonal (cos < 0.3): model has structured relational geometry
- If entangled (cos > 0.5): model is pattern-matching, not encoding structure
- If antonym == hypernym direction: surprising, publishable

* Method

1. For each word, capture residual stream at all 28 layers using
   "The word is: {word}" prompt
2. Compute relation vector: delta = act(target) - act(source)
3. Measure direction stability (cross-pair cosine) per relation per layer
4. Compute inter-relation angles at each layer
5. Report orthogonality in deep_semantics (L12-17)

* Dependencies

Pairs are hardcoded so nltk is not required to run. To regenerate or
expand the pair corpus from WordNet directly:

#+end_src

* The 0.6B Size Constraint

A 751M parameter model *must* encode hypernym relationships to function —
they're how generalization works. Antonyms are how negation works. The
question is where and how cleanly. Superposition at this scale means
relationships likely share dimensions, which is itself a finding.

If hypernym direction isn't stable at ANY layer, the model encodes
semantics differently than we think — surprising and publishable.
